设置

填一次就存在本地 data/settings.json，以后不用再填。推荐 DeepSeek：便宜、中文讲解好。
DeepSeek 就填 https://api.deepseek.com/v1，不要改。官网/申请页的网址不能填在这里。
在 platform.deepseek.com/api_keys 点「创建 API key」复制过来。只保存在本机。
deepseek-flash ＝ DeepSeek‑V4.1 Flash（便宜、快、还能看图）；deepseek-v4-pro 更强但贵好几倍。别写 “V4.1 Flash” 这种版本号，API 只认这两个名字。

错题本

每次解剖会自动存一份，点开可以重新载入当时的文章、题目和报告。也可以手动导入之前的 .md 报告。
支持「③ 解剖报告」里导出的文件

批量粘贴题目

把题目原文整段贴进来，能自动拆出题干和 A–D 选项。答案可以稍后手选。

生词本

查过的词会自动收进来。勾选要保留的，删掉已经会的，再导出成 PDF / Word 复习。

导入练习结果

做完导出的练习册后，把页面最下方那段「结果码」复制过来。做错的词会 +1 次并列入重点，做对的词下次复习时间往后推。

导出练习册

生成一个单文件 .html，发到 iPad / 手机的浏览器里就能做，不需要联网。
预览 可以直接试做，确认没问题再下载
